# 뉴스공장 출연자 집계 데이터

뉴탐사 데이터 페이지 https://newtamsa.org/p/newsfactory-guests 가 읽는 자료입니다.

- `data/episodes.json`: 뉴스공장 본방송 회차별 출연자. `d` 방송일, `v` 유튜브 영상 ID, `g` [이름, 방송일 기준 현직 국회의원이면 정당]
- `data/meta.json`: 회차 수, 기간, 갱신 시각
- 원자료: 유튜브 '겸손은힘들다' 채널 생방송 제목(한국어 원제목). 제목에 적힌 출연자만 셉니다.
- 집계: 뉴탐사. 오류 제보 news@newtamsa.org
